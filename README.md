# Info web
Um website colaborativo criado para conscientizar os usuários mais vulneráveis através de um sistema didático e prático que visa mostrar, com imagens e cards, termos importantes e essenciais para se proteger contra ameaças comuns no mundo digital, além disso, o site conta com um jogo interativo de caça palavras e um quiz para tornar tudo ainda mais didático!
